# כלכלת המשפחה – דשבורד

אתר סטטי (HTML + JS) שמציג את נתוני הכלכלה המשפחתית. מתאים למחשב ולטלפון.

## איך זה עובד
- `data/data.enc.json` – כל הנתונים האמיתיים, **מוצפנים** (AES-256-GCM, מפתח שנגזר מהסיסמה ב-PBKDF2, 250,000 סבבים). בלי הסיסמה הקובץ חסר משמעות, ולכן אפשר לשמור אותו גם במאגר ציבורי.
- `data/demo.json` – עותק עם שמות ומספרים בדויים, למשתמש הדמו (`demo` / `demo`).
- הפענוח קורה רק בדפדפן. הסיסמה לא נשלחת לשום מקום.

## הפעלה ב-GitHub Pages
1. צרו מאגר (מומלץ פרטי אם יש GitHub Pro, אחרת ציבורי – הנתונים מוצפנים) והעלו את כל התיקייה.
2. Settings → Pages → Deploy from branch → `main` / root.
3. הכתובת תהיה `https://ronen1m.github.io/FamilyView/` (רגיש לאותיות גדולות/קטנות) – פותחים אותה במחשב ובטלפון (בטלפון: "הוסף למסך הבית").

## עדכון נתונים מתוך האתר
- כפתור **עריכה** בכל עמוד מאפשר לשנות ערכים.
- **הגדרות → סנכרון עם GitHub**: מזינים owner, repo וטוקן (Fine-grained PAT עם Contents: Read & write למאגר הזה בלבד). אחרי זה "שמירה" מצפינה ומעדכנת את הקובץ במאגר ישירות – גם מהטלפון.
- בלי טוקן, "שמירה" מורידה קובץ `data.enc.json` שמעלים ידנית למאגר.

## כלים
- `tools/excel_to_json.py` – קורא את קובץ האקסל ומייצא JSON (לא להעלות את הפלט למאגר).
- `tools/build_data.py <json> <password>` – מצפין ובונה את קובץ הדמו.

## עריכת הדמו לכולם
הדמו (`data/demo.json`) לא מוצפן ומכיל רק נתונים בדויים.
- מי שאין לו טוקן: יכול לשחק בדמו, השינויים זמניים ונעלמים ביציאה.
- במכשיר שמוגדר בו טוקן GitHub (בהגדרות, בכניסה הרגילה): "שמירה" במצב דמו מעדכנת את `data/demo.json` במאגר, וכולם רואים את השינוי.

## עדכון נתונים מקבצים (בתפריט: "עדכון נתונים")
- **העלאת מסמך בנק / אשראי** – קובץ xlsx/xls/csv מהבנק או מחברת האשראי נקרא בדפדפן בלבד (`import.js`, בעזרת `vendor/xlsx.full.min.js`). מסווגים כל תנועה לקטגוריה, והסכומים מתווספים להוצאות/הכנסות. סיווגים נשמרים ככללים לפעם הבאה, תנועות שכבר נקלטו מזוהות, וכל קליטה ניתנת לביטול.
- **העלאת מסמך פנסיה וקרנות** – עדכון יתרות וקצבאות של הפנסיות, קרנות ההשתלמות והקרנות מקובץ אקסל (שיוך אוטומטי לנכסים) או ידנית מדוח PDF.
